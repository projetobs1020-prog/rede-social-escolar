# Conecta — Rede Social Escolar

Protótipo front-end dividido para um time de 4 pessoas.

## Pessoa 1 — Feed
- `js/feed/`
- `css/feed.css`
- posts, curtidas e comentários.

## Pessoa 2 — Usuários
- `js/users/`
- `css/profile.css`
- login visual, sessão, perfil e edição.

## Pessoa 3 — Grupos
- `js/groups/`
- `css/groups.css`
- grupos públicos/privados, busca, entrada e chat demonstrativo.

## Pessoa 4 — Segurança/Admin
- `js/security/`
- `css/admin.css`
- denúncias, automoderação, notificações, calendário, conquistas e painel administrativo.

## Integração
`js/app.js` inicializa tudo.

## Como executar
Abra `index.html` diretamente no navegador. Não há backend nesta versão.
